Place the two Word templates used by the Contract Generator here.

Required files:

- contract-basic-fee.docx
- contract-basic-fee-kpi.docx

Each template should contain the variables described in the project spec, for example:

{{Company Name}}
{{Date}}
{{Registered Company Name}}
{{Company address}}
{{Start Date}}
{{Duration}}
{{Fee Structure}}
{{Basic Fee}}
{{KPI}}        (only in contract-basic-fee-kpi.docx)
{{Percentage}} (only in contract-basic-fee-kpi.docx)
{{Payment Schedule}}
{{Expiry Date}}

Put the .docx files here and restart the backend server.
